# 自学编程的失败与重建：从985科班到B站网课的程序员之路

## 核心结论
> 作者作为985计算机科班出身，在校期间长期学不会编程、挂科、毕业即失业，最终通过B站网课（尤其是某马等UP主教程）从Java SE起步、系统自学Java Web/SSM/SpringBoot/Vue/uni-app 等全栈技术，才重新建立信心并准备求职。其核心方法论是：跟网课而非跟书本、用 Markdown 做笔记、坚持手敲代码在本机复现、遇到报错逐个排查，自学是计算机学习的唯一出路。

## 详细内容
## 背景

作者是国内某985高校计算机专业学生，在校期间长期处于"上课听不懂、下课不会配环境、二指禅敲键盘、连实验报告都要裁剪同学作业来交"的困境，最终混到毕业却不敢投简历。核心原因并非智力问题，而是**学习路径完全依赖课堂与书本**，缺乏可复现的动手环境。

## 转折点：从课堂到 [[B站]] 网课

工作数年后，作者重新拿起 Java，从 [[Java SE]] 开始跟某马、懒猫老师等 B 站 UP 主的网课系统学习，逐步扩展技能栈：

- **后端路线**：Java SE → [[Java Web]] + MySQL → [[SSM框架]] → [[SpringBoot]] → Spring Cloud 微服务与中间件
- **数据结构与算法**：高琪 Java300 中的设计模式 + 韩顺平 Java 数据结构与算法 → 敢看源码与刷 [[LeetCode]]
- **前端路线**：重学 HTML/CSS/JS → jQuery/Bootstrap → Vue2 + Element-UI → Vue3 之前先补 less/scss/TypeScript/[[uni-app]]
- **桌面与底层**：重学 C/C++ + [[Qt]] 跨平台桌面开发；补 Linux 基础命令

## 学习方法论（作者反复强调的"可复用经验"）

1. **绝不跟书本学，跟网课学**：书本只有伪码，无法帮你配环境；网课是"配工具+写代码"的手把手过程。
2. **练盲打先行**：金山打字通 + 搜狗输入法，保证代码字符敲正确。
3. **装好 [[Markdown]] 笔记工具**（Typora 破解版或正版），用 md 记录网课笔记、报错与解决方案。
4. **不会就搜，5/10/20/50/200 小时地学**：B站搜索一切问题——装软件、环境配置、版本依赖、网络报错、面试经验、考研 408 均可找到对应视频。
5. **本机复现 > 听懂**：1 小时网课 1.5 倍速播放 + 跟着敲 + 整理笔记，往往要 2.5–3 小时。前端阶段（webpack、node 版本依赖）经常一小时课耗半天。
6. **补办公技能**：Excel 看王佩丰，PS 看敬伟，避免被工具卡住。
7. **不折腾 Linux 发行版**：新手用 Windows 即可，有钱再上 Mac。

## 心路与教训

作者用"学不会→挂科→毕业→空窗考公考研失败→家人闲言碎语→最终靠学会 Java 走出内耗"复盘了近十年经历。其核心认知是：**焦虑不能解决任何问题，只有动手学、动手做，才能在它到来的那一天不再心慌**。

## 致谢与资源清单

- B 站教程 UP 主：青空の霞光、简说 linux、yaaangmin、pineforest、博哥 plus、踌躇月光、睡不醒的鲤鱼、谭玉刚、懒猫老师
- 培训机构公开课：某马（黑马程序员）
- 笔记工具：Typora（Markdown）、OneNote、OneDrive

## 可复用结论

对于完全小白或在校学不下去的计算机学习者，**最坏的结果也不过如此**。技术学习的唯一杠杆是自己的时间与坚持，网课 + 笔记 + 本机复现 + 报错即学，是被验证可行的最低成本路径。
