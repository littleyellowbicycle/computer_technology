# 从电路到C语言的计算机系统入门书单

## 核心结论
> 想打通软硬件、从底层电路一路学到高级语言，单一教材难以覆盖全程；社区公认的两本经典《计算机系统要素》（nand2tetris）与《编码》恰好互补，前者项目驱动从逻辑门搭建出可玩游戏，后者用通俗叙事讲透软硬件背后的原理。组合阅读可以形成从电路、汇编、编译到操作系统的完整学习闭环。

## 详细内容
想从最底层开始打通软硬件、把计算机的每一层都摸透，单纯找一本「从电路讲到 C 语言」的书并不容易——大多数教材只覆盖其中一两层。但社区里公认的两本经典读物合在一起，恰好覆盖了从 [[逻辑门]] 到 [[汇编语言]] 再到 [[C语言]] 的完整路径。

## 第一本：《计算机系统要素：从零开始构建现代计算机》

英文原名 *The Elements of Computing Systems: Building a Modern Computer from First Principles*，通常以项目代号 [[nand2tetris]] 著称。这本书最大的特点是**项目驱动**：读者从最基础的 [[NAND门]] 出发，先搭建 [[逻辑电路]] 与 [[ALU]]，再到 [[内存]] 与 [[CPU]]，亲手实现一个能跑程序的硬件平台；随后在硬件之上编写 [[汇编语言]]、设计 [[虚拟机]]，再到实现 [[编译器]]、[[操作系统]]，最终在自制的计算机上跑出一个完整的 [[俄罗斯方块]] 游戏。它是一门「既见树木，又见森林」的工程实践课，配套有免费公开课与软件工具链（nand2tetris.org），适合愿意边做边学的读者。

## 第二本：《编码：隐匿在计算机软硬件背后的语言》

英文原名 *Code: The Hidden Language of Computer Hardware and Software*。如果说第一本偏重动手实现，那这本则偏重原理讲解：作者用大量类比与图解，从 [[继电器]]、[[布尔代数]]、[[二进制]] 讲起，逐步过渡到 [[微处理器]] 与 [[机器码]]，最后落到 [[高级语言]]。整体阅读体验更加轻松，适合作为第一本的补充，或入门前的预热。

## 推荐的学习路径

两本书可以这样组合使用：
1. **先读《编码》**，建立对硬件与软件之间关系的直觉理解；
2. **再上手《计算机系统要素》**，完成一次完整的从下到上的构建。

这种「先读后做」的方式，比单独啃任何一本都更能帮助初学者把分散的知识点串成一条连贯的链——从 [[电路]]、[[汇编]]、[[编译原理]] 一直到 [[操作系统]] 与 [[应用程序]]，每一层都看得见、摸得着。
