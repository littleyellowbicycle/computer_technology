# 用 GitHub Codespaces 零成本获取云端编程环境

## 核心结论
> GitHub 为每个注册用户免费提供 [[GitHub Codespaces]] 云端开发环境，最高规格可达 16 核 CPU、128G 存储与千兆带宽，配合浏览器版 [[VSCode]] 即可实现远程编程。对于预算有限的学习者而言，这是一种几乎零成本替代高配电脑的方案，但因资源可能被滥用，政策长期可持续性存在不确定性。

## 详细内容
## 背景

很多编程初学者受限于硬件预算，难以在本地流畅运行现代开发工具链。一种被忽视的解决路径是：直接使用云端 [[IDE]]，把"电脑配置"问题转化为"网络连接"问题。

## 操作步骤

1. 注册一个 [[GitHub]] 账号并登录。
2. 在 GitHub 主页顶部找到 **Codespaces** 入口。
3. 创建容器实例，可选择最高规格：16 核处理器 + 128G 硬盘 + 千兆带宽。
4. 默认系统为 [[Ubuntu]]，通过浏览器内嵌的 [[VSCode]] 直接打开远程工作目录。
5. 在远端完成编译、运行、调试，本地仅承担"显示与输入"职责。

## 性能参考

据答主实测，该免费规格与一台万元级台式机几乎相当，下载与构建速度表现优异。

## 适用场景

- 入门阶段无预算购买开发机
- 临时需要高算力跑构建或训练任务
- 多设备切换，希望工作环境集中管理
- 配合 [[Git]] 进行版本控制实践

## 注意事项

- 该福利面向所有 GitHub 用户，但未做严格资格审核，滥用风险较高。
- 作者提示：使用人数过多可能导致官方调整甚至取消该政策，建议有需求时尽早使用。
- 容器有默认使用时长与休眠策略，长时间任务需留意资源限制。
- 网络质量直接决定体验，弱网环境下交互延迟明显。
