# 让人惊叹的优雅代码：算法、数据结构与代码高尔夫

## 经典算法中的极简之美

### 线性求逆元

仅用两行代码，在 O(n) 时间内求出 1 到 n 对模 m 的所有[[逆元]]：

```c
for (int i = 2; i < MAXN; i++)
    inv[i] = mul(inv[mod%i], mod - mod / i, mod);
```

### 最大公因数（辗转相除）

一行递归，把两千年前的数学智慧浓缩为极致简短的表达：

```c
int gcd(int x, int y){ return y ? gcd(y, x%y) : x; }
```

### 树状数组（Binary Indexed Tree）

单点修改 + 区间求和的最优解，利用二进制位运算 `i & -i` 实现[[前缀和]]与单点更新的统一：

```c
void add(int i, int x){
    for (; i <= n; i += i & -i) tree[i] += x;
}
int sum(int i){
    int ret = 0;
    for (; i; i -= i & -i) ret += tree[i];
    return ret;
}
```

### zkw 线段树

清华大学[[张昆玮]]（zkw）提出，把迭代式线段树的码量压到一分钟内可手写完成的程度：

```c
void set(int x, int value){
    val[x += treeLen] = value;
    while (x >>= 1) pushUp(x);
}
```

## 更深邃的算法

- **后缀数组 DC3 算法**：用三个数组代替两个，将构造复杂度降至 O(n)，体现天才级设计思路。
- **数论变换（NTT）**：[[快速傅里叶变换]]的模运算版本。费马素数群上的原根完美模拟复数单位根，使离散卷积在整数域内精确完成。
- **主席树（可持久化线段树）**：fotile 在考场上发明，用于 O(log n) 解决区间第 k 大问题，结构自然且优雅。
- **Pollard 因数分解**：将[[生日悖论]]与递推式循环节结合，期望时间复杂度达 n^0.25，是数论与随机化的巧妙融合。

## Tweetable Mathematical Art：140 字符的图像生成

Kyle McCormick 在 StackExchange 发起的比赛要求用 C++ 编写三个函数（RD/GR/BL），每个不超过 140 字符，生成 1024×1024 的图像。其中令人拍案的作品包括：

### 极坐标彩虹环

利用三角函数相位差构造 HSV 色彩环：

```c
unsigned char RD(int i,int j){
    return (char)(_sq(cos(atan2(j-512,i-512)/2))*255);
}
// GR、BL 仅相位偏移 2π/3
```

### 曼德博集合（Mandelbrot Set）

仅靠迭代公式 `z = z² + c` 配合对数映射，竟能用数十行代码画出经典分形：

```c
float x=0,y=0;int k;
for(k=0;k++<256;){
    float a=x*x-y*y+(i-768.0)/512;
    y=2*x*y+(j-512.0)/512;
    x=a;
    if(x*x+y*y>4) break;
}
return log(k)*47;
```

## 日期计算：Tomohiko Sakamoto 算法

仅需五行代码即可由年月日推算星期几——通过查表偏移巧妙规避闰年判断分支：

```c
int dow(int y, int m, int d) {
    static int t[] = {0, 3, 2, 5, 0, 3, 5, 1, 4, 6, 2, 4};
    y -= m < 3;
    return (y + y/4 - y/100 + y/400 + t[m-1] + d) % 7;
}
```

更极致的代码高尔夫版本甚至把月份表替换为字符串 `"-bed=pen+mad."`，用字符 ASCII 码替代数字。

## 美之共性

无论是[[算法竞赛]]中的数据结构设计，还是代码高尔夫中的极短表达，震撼人心的代码都有相似的特质：

- **结构精巧**：用最少的逻辑单元完成复杂任务；
- **数学自洽**：每一步推导环环相扣，无冗余分支；
- **直观可读**：理解之后难以忘记，成为直觉的一部分。

正如原答主所言："和数据结构或数学有关的算法都是非常优美的，前者在于设计的精巧性，后者在于证明的环环相扣。"
