# 计算机科学自学路线与经典书籍

## 核心结论
> 计算机科学自学应遵循"先全局认知、后系统基础、再深入专研"的路径：先看《计算机科学速成课》建立全景图，再依次攻克计算机组成原理、操作系统、编译原理、数据结构与算法、计算机网络五大基础课。每个学科按"入门 → 基础 → 实战"分层选材，配合视频课程与动手实践，避免直接啃经典导致挫败感。

## 详细内容
## 全局认知：建立全景图

对于非科班或刚入门的自学者，建议先在 B 站观看《计算机科学速速课》视频，用半个月时间建立计算机世界的整体认知——从硬件搭建、指令执行，到操作系统、网络与算法的全貌。这是进入 [[计算机科学]] 的最佳入门入口。

## 五大基础课程体系

计算机科学的核心内功在于以下五门课程，建议按顺序系统学习：

### 1. [[计算机组成原理]]

揭示计算机硬件如何工作，是理解所有上层软件的基石，也是解答日常电脑问题的底层依据。

### 2. [[操作系统]]

操作系统的核心设计思想是"向下屏蔽差异，向上提供统一"，这一理念本身就能迁移到日常开发中。四大核心模块推荐学习顺序为：[[内存管理]] → [[进程管理]] → [[文件系统管理]] → [[输入输出设备管理]]。学完后才能真正理解：

- **虚拟内存与虚拟文件系统**：本质都是统一抽象层
- **进程与线程的最大区别**：线程共享同一进程的虚拟内存，上下文切换无需切换页表，开销更小
- **TLB**：缓存常用地址映射关系以加速页表查询
- **磁盘高速缓冲区**：操作系统预读、缓存、合并 I/O 请求以减少磁盘访问

注意不要将通用"操作系统"概念与具体 [[Linux 内核]] 实现混淆，应先掌握通用原理，再研究 Linux 细节。

### 3. [[编译原理]]

难度较高，需在掌握前两门课程的基础上学习，涉及编译过程、计算机工作原理与数学知识的综合积累。

### 4. [[数据结构与算法]]

核心理念："程序 = 数据结构 + 算法"。学习应分三步走：

- **入门阶段**：通过科普读物建立感性认识
- **实践阶段**：亲手实现基础数据结构与算法
- **原理阶段**：理解背后的数学原理

无论是否感兴趣，面试必考，是程序员的核心竞争力。

### 5. [[计算机网络]]

相对最好学，因为协议可通过抓包观察与验证，不会因设备不同而不同（大家遵循 [[TCP/IP 网络模型]]）。

四层结构中重点掌握：

- **应用层**：[[HTTP]] / [[HTTPS]]
- **传输层**：[[TCP]] / [[UDP]]
- **网络层**：[[IPv4]]

建议从 `ping` 命令的工作过程入手，理解数据包如何跨层转发，由此打通整个协议栈。

## 分层学习资源

### 操作系统

- **入门视频**：清华大学《操作系统》（向勇、陈渝）、哈工大《操作系统》（李治军，从 Linux 内核视角讲解）
- **入门书籍**：《[[现代操作系统]]》
- **深入**：《[[操作系统导论]]》（细节丰富）、《[[深入理解计算机系统]]》（CSAPP，豆瓣 9.8 分，综合性强，锻炼计算思维）

### 数据结构与算法

- **入门**：《[[大话数据结构]]》《[[算法图解]]》（两天可读完，通俗有趣）
- **基础**：《[[数据结构与算法分析]]》（有 C/C++/Java 三个语言版本）
- **面试实战**：《[[剑指 offer]]》《[[编程珠玑]]》（海量数据处理技巧）《[[编程之美]]》（微软工程师出品，难度较高）
- **配套练习**：[[LeetCode]] 刷题平台

### 计算机网络

- **入门**：《[[图解 HTTP]]》《[[图解 TCP/IP]]》《[[网络是怎样连接的]]》
- **视频**：B 站湖科大《计算机网络微课堂》
- **深入**：《[[计算机网络：自顶向下方法]]》、《[[TCP/IP 详解]] 卷一：协议》（网络圣经）、《The TCP/IP GUIDE》（TCP 滑动窗口与流量控制部分讲解最佳）
- **权威资料**：[[RFC 文档]]（协议最权威解释，三次握手/四次挥手的根源）
- **实战工具**：[[Wireshark]] 抓包分析

## 学习方法论

1. **切忌直接啃经典**：《算法导论》《深入理解计算机系统》等经典书直接阅读极易劝退，应从入门书建立信心后再升级。
2. **视频与书籍结合**：先看视频的某一章节，再阅读书籍对应章节，效率远高于纯啃书。
3. **重视动手实践**：算法要亲手实现，网络要亲手抓包观察报文，操作系统可读 [[Linux 内核]] 源码。
4. **追问"为什么"**：不仅要学 What 与 How，更要理解"为何引入此算法/概念"，培养 [[计算思维]]。
5. **分层递进**：入门 → 基础 → 深入 → 实战，逐级提升，避免在错误的难度上消耗热情。

## 学科之间的关联

五门基础课并非孤立：

- **计算机组成原理 + 操作系统**：通过 [[CSAPP]]（深入理解计算机系统）打通，理解程序从硬件到操作系统的完整执行链路。
- **数据结构与算法 + 操作系统**：操作系统的进程调度、内存分配、文件系统都深度依赖数据结构。
- **计算机网络 + 操作系统**：网络协议栈本身就是操作系统的子系统，TCP 内核参数调优需要双重视角。

掌握这五门课程的"内功"后，再学任何编程语言、框架或领域（AI、Web、后端）都会事半功倍。
