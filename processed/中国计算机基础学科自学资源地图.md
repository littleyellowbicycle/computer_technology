# 中国计算机基础学科自学资源地图

## 核心结论
> 国内高校计算机课程常被吐槽体系陈旧、讲解枯燥，自学者应以国际公开课与精品中文课为主线，补齐[[操作系统]]、[[计算机组成原理]]、[[编译原理]]、[[数据结构与算法]]、[[计算机网络]]与[[数据库]]六大基础学科。本笔记整理 CrashCourse、MIT、清华、哈工大等公开课资源，构成一条可落地的 CS 自学路线。

## 详细内容
## 为什么大学 CS 教育常被吐槽

知乎热门问题"为什么中国的计算机教育这么差？"下流传着一张调侃图：把谭浩强、马士兵、廖雪峰、侯捷等老师冠以"C / Java / Python / C++ 之父"的名号——笑点在于**真正掌握一门语言，靠的不是某本教材或某位老师，而是反复读官方文档与源码**。这折射出国内部分高校课程的两大问题：教材陈旧、过度依赖某本"圣经"，以及课堂讲解脱离工业实践。

要弥补这些短板，靠自学完全可以实现。下面按学科给出经过社区验证的高质量课程。

## 计算机科学通识入门

强烈推荐 CrashCourse 出品的[[计算机科学速成课]]（B站中文字幕版），共 41 个短视频，每个 10 分钟左右，覆盖：

- 计算机早期史 → 电子计算 → [[布尔逻辑]]与逻辑电路
- [[二进制]]表示 → 算术逻辑单元（ALU）→ 寄存器与内存
- 中央处理器（CPU）→ 指令与程序 → 高级 CPU 设计
- 编程语言演进 → 编程原理（语句、函数、算法）
- 数据结构与 [[算法初步]]
- 软件工程、集成电路与摩尔定律
- [[操作系统]]、[[文件系统]]、压缩、命令行界面
- [[计算机网络]]、互联网、万维网、网络安全、加密、黑客与攻击
- [[机器学习与人工智能]]、[[计算机视觉]]、[[自然语言处理]]、机器人

适合碎片化时间建立完整 CS 心智模型，是大学课程的最佳入门补充。

## 操作系统

[[操作系统]]是连接所有编程语言与底层硬件的枢纽。不懂进程/线程调度、内存分配、JVM 原理，后续学习处处碰壁。推荐课程：

- **清华大学 ucore 实验课**（向勇、陈渝）：从零搭建一个五脏俱全的小操作系统
- **MIT 6.828**：完成 6 个实验即可实现简易内核，需先掌握 C 与汇编
- Udacity Advanced OS 公开课

核心知识点：进程与线程、进程状态与通信、调度算法、死锁（含 Java 解决方式）、[[内存管理]]、虚拟内存与分页、页面置换算法、静态/动态链接。

## 计算机组成原理

学习计算机的基本组成与内部运行机制，理解软硬件交互与性能优化。推荐：

- **哈工大刘宏伟**《计算机组成原理》：考研与初学者皆宜
- **MIT 6.004 Computation Structures**（Spring 2017，中文字幕版）：英文可则强烈推荐，质量极高

## 编译原理

理解高级语言如何被翻译成机器语言，学完后可尝试实现一个小型面向对象语言编译器。推荐：

- 哈工大《编译原理》（陈鄞）：PPT 精美、通俗易懂
- 国防科技大学《编译原理》：视频简洁，适合多刷

前置知识：程序设计语言、数据结构与算法、计算机组成原理、离散数学。

## 数据结构与算法

程序员内功的核心体现，也是面试/笔试必考项。推荐课程：

- **UC San Diego** Coursera 算法专项课
- **浙大陈越姥姥**《数据结构》：经典中的经典
- **小甲鱼**《数据结构与算法》

学习内容：数组、链表、栈、队列；二叉树、AVL 树、B 树、红黑树；堆结构；排序算法（冒泡、选择、插入、快速、归并、堆排序）及时空复杂度；[[动态规划]]、回溯、贪心、递归、位运算。

配套刷题平台：

- **[[LeetCode]]（力扣）**：test case 完备，社区讨论区高质量
- **牛客网**：覆盖 IT 题库 + 面试 + 求职 + 内推
- **LintCode**：UI 与 tagging 更灵活

建议每天一题，坚持半年即可从容应对中等难度。

## 计算机网络

掌握计算机分层结构（物理层 → 应用层），深入 [[TCP/IP]] 协议族。推荐：

- 教材：《计算机网络：自顶向下方法》（Kurose & Ross）
- **中科大郑烇、杨坚**：自顶向下方法第 7 版配套视频（2020 秋自动化系录制）
- 哈工大李全龙《计算机网络》

核心知识点：网络分层结构、TCP/IP、三次握手四次挥手、滑动窗口与拥塞控制、HTTP/HTTPS、网络安全（CSRF、XSS、SQL 注入）。

## 数据库

数据密集型应用是工业界主流，数据表就是数据结构、索引与查询就是算法。推荐：

- **入门**：《MySQL 必知必会》
- **进阶**：《高性能 MySQL》：索引、SQL 优化、锁与事务、高可用架构
- **UC Berkeley CS168 / CS186**：英文经典公开课
- **中国人民大学王珊**《数据库系统概论》

## 配套资料

- 谷歌大佬整理的 300 道 LeetCode 最优解手册
- 200+ 本计算机经典书籍 PDF（涵盖 C/C++/Java/Python/前端/数据库/网络/算法/ML）
- 图解 PDF 系列：操作系统、网络、计算机组成原理

## 学习建议

1. **先广后深**：用计算机科学速成课建立全景图，再选一门深入
2. **理论 + 实验**：MIT 6.828、清华 ucore 都强调动手实现
3. **刷题闭环**：学完数据结构后立即上 LeetCode 巩固
4. **官方文档 > 圣经**：读 [[Python]]、[[Java]] 官方文档比任何"之父"教程更可靠
