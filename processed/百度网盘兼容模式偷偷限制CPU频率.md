# 百度网盘兼容模式偷偷限制CPU频率

## 核心结论
> 百度网盘 Windows 版在闪崩后会自动启用隐藏的系统兼容模式，通过修改 Windows 电源计划强制限制 CPU 频率并阻止睿频，导致整机性能严重下降；该设置不写入注册表而是保存在软件目录，因此重装系统、迁移硬盘后依然生效，是一种典型的越权修改用户系统设置的行为。

## 详细内容
## 事件经过

知乎用户 @江卓尔 在自己的 [[戴尔 XPS17]] 笔记本（Win10 LTSC）上遭遇一次令人崩溃的故障排查经历：系统严重卡顿，播放 B 站 4K 视频也会卡顿，[[CPU-Z]] 基准跑分仅剩正常值的一半，[[CPU睿频]] 始终被锁死。

排查路径如下：

1. 先怀疑外接电源硬件问题。笔记本原装 130W 充电器经 USB-C 接显示器后只剩 90W 充电功率，功耗仪显示拷机仅 65W（正常应 120W 以上）。更换电源、换充电口均无效。
2. 怀疑 Win10 系统电源管理故障。用 Ghost 备份的干净系统恢复后，第一时间能正常睿频，但第二天问题复现。多次 Ghost 恢复都只能维持一到两天。
3. 尝试 BIOS 设置、powercfg 命令、RTC 重置、Dell Power Manager 等方案，全部无效。

最终偶然看到知乎相关提问，才发现是 [[百度网盘]] 的系统兼容模式在作怪。回想起来，百度网盘确实曾闪崩过一次，此后就踩坑了。取消勾选后无需重启，CPU 频率立即恢复正常。

## 作弊机制

百度网盘闪崩后会自动启用系统兼容模式，该选项具有以下恶劣特性：

- 隐藏开关：默认设置面板里不显示，要崩溃后才会出现该选项。
- 修改系统全局电源计划：通过修改 [[Windows电源计划]]，限制 [[CPU睿频]] 与电压。
- 进程退出后仍生效：即使关闭百度网盘，限制依然存在。
- 持久化在软件目录：配置不写入 Windows [[注册表]]，而是保存在百度网盘自己的安装目录下，重装 Windows 也不会覆盖。
- 跨设备传染：作者习惯把非系统盘整体复制到新电脑，这意味着问题设置会一并迁移到新机器，换电脑也无法摆脱。
- Ghost 恢复干净系统后只要启动百度网盘，立即复发。

## 影响范围

- 作者家中另一台 [[戴尔外星人]] 游戏本也命中同一问题，表现为闲置关闭显示器后第二天可能死机（一周一两次概率），取消勾选后几个月稳定不宕机。
- B 站网友已逆向相关代码，确认了百度的具体改动逻辑。
- 期间偶尔出现的 Win 任务栏卡死（任务管理器重启资源管理器才能恢复），作者怀疑也与百度网盘有关。

## 作者立场与教训

作为从 DOS 6.22 时代开始 DIY 的老程序员，作者认为百度内部负责系统兼容模式这条线的产品经理、架构师、程序员、测试全部裁掉一点都不冤枉。

处理掉兼容性问题的正确方式至少有十几种，百度却选择了最差的一种——不分青红皂白一刀切，直接修改用户系统电源设置。即便 Intel 13/14 代 CPU 存在缩肛问题，这也不是百度粗暴限制睿频的借口，更何况作者的 CPU 根本不是这两代。

讽刺的是，作者因 [[3-2-1备份原则]]（3 份副本、2 种介质、1 份异地）仍在使用百度网盘：NAS 跑 [[RAID 1]] 加关键数据异地备份到百度网盘（31T 空间开了 SVIP10）。鉴于迁移成本太高，未来计划用 [[Sandboxie Plus]] 等沙盒软件隔离运行百度网盘，防止它再次越权染指系统设置。

## 排查启示

- 第三方应用崩溃后可能留下隐藏的全局副作用，且副作用持久化位置不一定在系统注册表。
- 怀疑系统级性能问题时，可优先检查 powercfg /energy 报告与第三方软件的电源计划写入行为。
- 重装系统前若需保留部分非系统盘数据，应警惕应用配置被一并迁移的风险，必要时在沙盒或虚拟机中运行不可信软件。
