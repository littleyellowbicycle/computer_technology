# 新手使用GitHub与计算机基础学习路线

## 核心结论
> HelloGitHub 是编程新手发现优质开源项目的最佳入口，每月以月刊形式更新涵盖各语言入门级项目。计算机基础（组成原理、操作系统、网络、数据结构与算法）是校招与社招的共同核心考察点，应通过视频课程搭配经典书籍的方式分层系统学习，而非直接啃经典大部头。

## 详细内容
## 一、HelloGitHub：新手友好的开源项目入口

新手使用 [[GitHub]] 时常见的问题是不知道哪些项目值得入手。[[HelloGitHub]] 项目正是为解决这一痛点而生：每月 28 日以月刊形式更新，面向编程新手、开源爱好者，持续运营三年多，标星 1.6w+。

第 43 期内容覆盖多语言典型项目，例如：

- **C**：[[tmux]]，终端复用工具，支持窗口分割、多缓冲区复制粘贴，可显著提升命令行效率。
- **C#**：[[BenchmarkDotNet]]，功能强大的 .NET 基准测试库。
- **C++**：[[dbg-macro]]，受 Rust 启发的 header-only 调试宏，支持彩色输出与变量名自动打印。
- **Go**：[[go-admin]]，基于 Gin + Vue 的数据可视化与管理平台，开箱即用 RBAC 认证。
- **Java**：`eladmin`，基于 [[Spring Boot]] 2.1.0 + Vue 的前后端分离后台管理系统，技术栈覆盖 Redis、Swagger、Druid、Freemarker，适合作为实战项目。
- **JavaScript**：`chart-race-react`，简单的 [[React]] 长条图赛跑动画组件。
- **Python**：[[TagUI-Python]]，自动化操作库，可实现自动打开网页、输入与截图。
- **Ruby**：`shift`，在线 MySQL 数据库迁移工具。
- **Swift**：`Percent`，让 Swift 支持百分比类型，消除精度缺失。
- **其他**：`cascadia-code`（微软开源等宽字体，支持字符组合）。
- **开源书籍**：`python_ebook`、`Cosmic Python`（英文）。
- **教程**：`BigData-Notes`（Hadoop、Spark、Storm、HBase、Hive、ZooKeeper、Kafka 入门）。
- **机器学习**：`dimensionality_reduction_alo_codes`，用 Python 实现 11 种经典降维算法。

## 二、计算机基础的核心地位

互联网技术岗招聘主要考察两块：**[[计算机基础]]**（计算机原理、网络、算法、数据结构）与**专业技能知识**。两者在[[校招]]与[[社招]]中的权重不同：

- 校招：计算机基础约 90%，专业知识约 10%。
- 社招：计算机基础约 20%，专业知识约 80%。

计算机基础相当于内功，专业技能相当于外功，**基础不牢，地动山摇**。以权限系统设计为例：熟练掌握[[数据结构]]的人会自然想到用 [[bitmap]]（uint64）存储 64 种细分权限，而基础薄弱者可能花一周写出十几个糟糕的接口。

## 三、计算机基础学习路线

推荐采用「**视频课程入门 + 书籍深入**」的组合方式。第一遍视频快速过完，后续边看边思考，不要抄代码，多与视频方案「对着干」以减少路径依赖。

### 0. 入门导览

零基础可先看 **[[Crash Course]] 计算机科学速成课**（B 站有汉化版，40 集，每集约 10 分钟，10 小时可粗略建立计算机科学整体认知）。

### 1. 计算机组成原理

- **入门书籍**：《计算机是怎样跑起来的》《程序是怎样跑起来的》《网络是怎样连接的》（图灵「三步曲」，通俗易懂）。
- **进阶书籍**：《Computer Organization》《计算机组成与设计：硬件/软件接口》《深入理解计算机系统（CSAPP）》《计算机组成：结构化方法》《计算机体系结构：量化研究方法》。
- **国外视频**：伯克利 [[SICP]]（CS61A）、Harvard [[CS50]]、MIT 6.001。
- **国内视频**：清华大学刘卫东、哈工大刘宏伟（135 讲）。

### 2. 计算机操作系统

操作系统是学习多线程、内存分配、Linux 等知识的底层支撑，[[操作系统]]知识频繁出现在笔试中。

- **书籍**：《现代操作系统》《操作系统导论》《深入理解计算机系统》《自己动手写操作系统》《操作系统真象还原》。
- **国外视频**：MIT 6.828（基于 xv6）、Udacity Advanced OS。
- **国内视频**：清华大学《操作系统原理》、哈工大李治军（32 讲）。

### 3. 计算机编译原理

编译原理难度高且枯燥，需要先积累组成原理与操作系统的基础。

- **书籍**：《编译器设计（第二版）》《编译原理》。
- **国外视频**：Stanford CS143、CS243；CMU 15-411。
- **国内视频**：哈工大（81 集）、东南大学廖力（64 讲）。

### 4. 计算机网络

[[计算机网络]]是除操作系统与算法外的另一大面试常考方向。

- **书籍**：《网络是怎么连接的》《计算机网络：自顶向下方法》《图解 HTTP》。
- **国外视频**：Stanford CS144、UMass Wireshark Labs。
- **国内视频**：方老师《计算机网络》（谢希仁第七版）、哈工大李全龙。

### 5. 数据结构与算法

**程序 = 数据结构 + 算法**。学习建议分三层：

1. **入门阶段**：通过科普读物建立感性认识。
2. **实践阶段**：亲手实现常用数据结构与算法。
3. **原理阶段**：理解背后的数学原理。

**书籍推荐（分层）**：

- **入门**：《大话数据结构》《算法图解》。
- **基础**：《数据结构与算法分析》（C / C++ / Java 三个语言版本，系统全面）。
- **面试实战**：《剑指 Offer》《编程珠玑》《编程之美》。

**视频推荐**：

- **国外**：Stanford Algorithms（Tim Roughgarden）、UCSD 数据结构与算法、Princeton Algorithms Part I。
- **国内**：浙大陈越/何钦铭《数据结构》、北大张铭《数据结构与算法 C++ 版》、武大李春葆《数据结构》。

**可视化辅助**：visualgo.net、USFCA Data Structure Visualization，可直观看到排序、链表、红黑树等动画。

**刷题**：以《剑指 Offer》为面试核心，搭配 [[LeetCode]] 系统训练，参考「BAT 大佬 LeetCode 刷题笔记」。

## 四、给在校大学生的建议

计算机基础是伴随整个职业生涯的能力，不会像高考理综一样被遗忘。在校期间应把绝大部分时间投入到计算机基础上——这是拉开与培训出身程序员差距的关键，也是进入大厂的核心竞争力。
